根据想学习的内容和探索深度选择工作坊。**入门体验**将引导你了解 GitHub Copilot；**真实开发场景**则通过完整应用和团队待办事项，练习面向生产环境的工作流。

## 入门体验

通过聚焦的引导式实践了解 GitHub Copilot 产品的主要功能，无需准备现有代码库。

### [GitHub Copilot app 导览][first-steps-app]

从空文件夹构建 Space Quiz，将其发布到 GitHub，实现一个议题，完成 Copilot 审查，安排自动化任务，并探索 Canvas 工作流。

### [GitHub Copilot CLI 入门][first-steps-cli]

在终端中构建同一个 Space Quiz、审查差异、在工作树中并行运行会话、编辑前先规划，并在不离开 shell 的情况下创建、合并和委派拉取请求。

### [Visual Studio Code 入门][first-steps-vscode]

在 VS Code 中构建 Space Quiz，使用集成浏览器测试，通过源代码管理发布，借助 GitHub 工具处理议题和拉取请求，并将工作交接给云会话。

## 真实开发场景

使用 Tailspin Toys 应用和待办事项，在真实的软件开发生命周期中练习 GitHub Copilot。选择适合的工作环境，然后规划、构建、测试、审查并交付有意义的更改。

### [浏览真实开发场景工作坊][real-world-development]

可选择 GitHub Copilot CLI、GitHub Copilot app、GitHub Copilot cloud agent 或 Visual Studio Code。

> [!CAUTION]
> GitHub Copilot 的结果具有概率性，并非确定性，因此生成的代码和更改的文件可能与示例不同。出现细微差异是正常的。
>
> 如果在讲师带领的工作坊中遇到故障或运行异常，请向导师寻求帮助。
